# Factory improvement backlog

This prioritized backlog is maintained by the daily factory-improvement loop. It tracks factory friction, invariant violations, and opportunities to move invariants from Planned, Guarded, or Partial to Enforced. Entries must contain only aggregate metrics and sanitized process descriptions; never include transcript excerpts, credentials, personal data, user content, or proprietary source.

## Priorities

No validated factory improvements are queued yet. The first authorized daily run establishes the session boundary and adds only findings supported across implementation-agent transcripts.

## Entry format

Each future entry records priority, affected invariant ID, current enforcement status, violation or enforcement gap, expected reliability and token/cost impact, sanitized evidence, proposed verifier or workflow change, owner, and acceptance proof. Prefer a deterministic verifier over prompt guidance. An invariant moves to Enforced only when the same change adds passing proof.
